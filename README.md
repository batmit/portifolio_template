## Sobre este catálogo

O catálogo reúne os 47 outros repositórios públicos da conta batmit identificados em 01/11/2026. O próprio repositório do portfólio não é repetido como projeto. Os 10 destaques incluem trabalhos acadêmicos, pesquisa e desenvolvimento web.

Repositórios iniciais e modelos estão identificados como arquivo. Estudos e materiais de terceiros são descritos como tal.
